#### 1. Uniform Resource Identifier (URI)
- **Definition**: A compact sequence of characters that identifies an abstract or physical resource.
- **Types**:
    - **URL (Uniform Resource Locator)**: Identifies a resource and describes its primary access mechanism (e.g., network location).
    - **URN (Uniform Resource Name)**: Uniquely identifies a resource by name (e.g., ISBN), requiring registration under well-defined rules.
    - **IRI (Internationalized Resource Identifier)**: An extension of URI that supports Unicode characters.
- **URI Syntax**: `scheme:[//[user:password@]host[:port]][/path][?query][#fragment]`
    - `scheme`: Specifies the identifier (e.g., `http`, `ftp`, `telnet`).
    - `authority`: Includes optional authentication (`user:password`), the `host` (domain or IP), and an optional `port`.
    - `path`: Hierarchical data separated by slashes.
    - `query`: Attribute-value pairs separated by delimiters.
    - `fragment`: Pointer to a secondary resource (e.g., a section heading).

#### 2. MIME (Multipurpose Internet Mail Extensions)
- **Purpose**: A standard for encoding information for email and the web.
- **Media Types**: Defines types (e.g., `text`, `image`, `audio`) and subtypes (e.g., `plain`, `html`, `xml`).
- **Headers**: Defines headers used by SMTP and HTTP, such as `Content-Type`.
- **Multipart Media Type**: Allows combining multiple data sets in one body using boundary delimiters.
    - Used for web forms and file uploads via `multipart/form-data`.
    - `application/x-www-form-urlencoded` is noted as a more compact alternative.
- **Java Implementation Details**:
    - Configuration for `multipart/form-data` in `web.xml` includes: maximum upload file size, maximum whole request size, and the threshold for writing to disk instead of memory.
    - Email management via `jakarta.mail-api` and a `MailManager` class that reads SMTP configuration (host, port, username, password, sender) from a `mailManager.properties` file using an `InputStream`.
    - Uploaded photos are handled as `byte[]` (byte arrays).
