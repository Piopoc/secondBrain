# WA Course Summarization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create detailed summaries for all "WA - " folders in `raw/` and save them in `summaries/WA/`.

**Architecture:** Sequential analysis of each folder. For each folder, all files are read, analyzed, and synthesized into a single markdown summary file.

**Tech Stack:** Bash, Markdown, OpenCode tools (`glob`, `read`, `write`).
