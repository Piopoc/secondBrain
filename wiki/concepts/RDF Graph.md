# RDF Graph

An **RDF Graph** is a collection of RDF triples. It can be visualized as a directed graph where:
- **Nodes** represent the subjects and objects (resources).
- **Edges (Arcs)** represent the predicates (relationships).

Because RDF uses global URIs, graphs from different sources can be merged seamlessly. If two graphs use the same URI for a resource, they are automatically linked, enabling the creation of a massive, interconnected web of data.
