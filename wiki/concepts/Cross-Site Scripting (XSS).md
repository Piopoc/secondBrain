# Cross-Site Scripting (XSS)
A security vulnerability where an attacker injects malicious client-side scripts (usually JavaScript) into a web page viewed by other users. This allows the attacker to bypass the Same-Origin Policy and steal session cookies, deface websites, or redirect users.
