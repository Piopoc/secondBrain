# Linked Data

**Linked Data** is a set of best practices for publishing and interlinking structured data on the Web. The goal is to create a global database where data from different sources can be easily connected and queried.

## Linked Open Data (LOD)
When Linked Data is published under an **open license**, it is referred to as **Linked Open Data (LOD)**.

## The Four Principles of Linked Data
Defined by Tim Berners-Lee:
1. **Use URIs as names for things:** Identify not just documents, but real-world objects and abstract concepts.
2. **Use HTTP URIs:** Ensure that these names can be looked up (dereferenced) over the web.
3. **Provide useful information using standards:** When a URI is looked up, return data in a standard format like **RDF**.
4. **Include links to other URIs:** Enable the discovery of related information across different datasets.
