# Sigmoid Function

A mathematical function that maps any real-valued number into a value between 0 and 1.

## Formula
$$\sigma(x) = \frac{1}{1 + e^{-x}}$$

## Usage
Primarily used in [[Logistic Regression]] to represent probabilities.
