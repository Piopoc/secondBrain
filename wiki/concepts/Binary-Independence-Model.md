# Binary Independence Model (BIM)

The **Binary Independence Model (BIM)** is a foundational probabilistic model for IR.

## Core Assumptions
1. **Binary**: A document is represented as a binary vector (term present or absent).
2. **Independence**: The presence of one term is independent of the presence of any other term.

## Logic
It treats retrieval as a binary classification problem: given a query, what is the probability that a document belongs to the "Relevant" class vs the "Non-Relevant" class?
