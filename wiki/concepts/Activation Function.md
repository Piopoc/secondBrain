# Activation Function

A mathematical function applied to the output of a neural network node to introduce non-linearity into the model.

## Purpose
Without an [[Activation Function]], a neural network would behave like a single linear regression model regardless of the number of layers.

## Examples
- [[Sigmoid Function]]
- [[Softmax Function]]
