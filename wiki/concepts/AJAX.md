# AJAX (Asynchronous JavaScript And XML)

**AJAX** is a set of web development techniques that allow a web page to communicate with a server asynchronously, meaning it can exchange data and update parts of the page without requiring a full page reload.

## Core Mechanism
AJAX uses **scripted HTTP** to initiate requests. The primary goal is to create responsive web applications that feel like desktop software by avoiding the "blink" of a page refresh.

## Key Benefits
- **Improved User Experience:** Pages are more responsive and fluid.
- **Reduced Bandwidth:** Only the necessary data is transferred, not the entire HTML page.
- **Asynchronous Processing:** The user can continue interacting with the page while data is being fetched in the background.
