# JSP Lifecycle
The process by which a JSP page is transformed into a servlet: Translation (JSP $\rightarrow$ Java) $\rightarrow$ Compilation (Java $\rightarrow$ Bytecode) $\rightarrow$ Loading $\rightarrow$ Initialization (`jspInit`) $\rightarrow$ Execution (`_jspService`) $\rightarrow$ Destruction (`jspDestroy`).
