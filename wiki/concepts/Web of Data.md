# Web of Data

The **Web of Data** (or Web 3.0) is the evolution of the original "Web of Documents." While the original web was designed for human consumption of hypertext, the Web of Data is designed to be accessed and processed by both humans and machines.

## Key Characteristics
- **Typed Links:** Resources are connected by explicit, typed relationships.
- **Machine-Readable:** Data is structured so that machines can autonomously perform reasoning, integration, and discovery.
- **Interoperability:** Aims to break down "data silos" by using common frameworks for describing and linking data.

## Relation to Web of Documents
The Web of Data does not replace the Web of Documents but extends it. It adds a layer of semantics to the existing infrastructure, transforming raw data into meaningful information through the use of schemas and ontologies.
