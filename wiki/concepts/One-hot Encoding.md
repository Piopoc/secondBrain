# One-hot Encoding

A representation of categorical variables as binary vectors.

## Mechanism
A vector of size $V$ (vocabulary size) where only the index corresponding to the specific category is 1, and all others are 0.

## Usage
Commonly used as the initial input for [[Neural Language Models]] before being transformed into an [[Embedding Vector]].
