# Hidden State

In the context of [[Recurrent Neural Networks]], the hidden state is a vector that represents the "memory" of the network.

## Function
It stores a compressed representation of the sequence of inputs seen up to the current time step. This allows the network to maintain context, which is essential for tasks like language modeling where the meaning of a word depends on previous words.
