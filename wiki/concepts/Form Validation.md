# Form Validation

**Form Validation** is the process of checking if the data entered into a web form is correct and complete before it is submitted to the server.

## Objectives
1. **Data Integrity:** Ensuring data is in the correct format (e.g., email addresses contain '@').
2. **Security:** Protecting the application from attacks like SQL Injection or XSS.
3. **User Experience:** Providing immediate feedback to help users correct errors.

## Validation Types
- **Client-Side:** Occurs in the browser. Fast, user-friendly, but can be bypassed.
- **Server-Side:** Occurs on the server. Slower, but essential for security and data integrity.
