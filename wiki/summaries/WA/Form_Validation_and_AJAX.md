# Form Validation and AJAX

## Form Validation
Form validation ensures that user-provided data is correct, secure, and complete before being processed by the server.

### Validation Strategies
- **[[Client-Side Validation]]**: Provides instant feedback using **HTML5** attributes or **JavaScript**. It improves UX but can be bypassed.
- **[[Server-Side Validation]]**: The final line of defense. Ensures data integrity and security against attacks like SQL Injection.
- **[[Form Validation]]**: The general process of combining both strategies to ensure the "right data in the right format."

## AJAX (Asynchronous JavaScript And XML)
**[[AJAX]]** allows web applications to exchange data with a server without reloading the page, creating a more responsive, desktop-like experience.

### Implementation Technologies
- **[[XMLHttpRequest]]**: The legacy API for asynchronous requests.
- **[[Fetch API]]**: The modern, Promise-based replacement for XHR.
- **[[JSON]]**: The standard data format for AJAX communication, utilizing serialization and deserialization.
- **[[CORS]]**: The mechanism that allows AJAX requests to cross different domains safely.

## Practical Applications
Common use cases include live search (autocomplete), real-time username availability checks, and dynamic shopping cart updates.
