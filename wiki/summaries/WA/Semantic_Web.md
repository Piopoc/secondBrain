# Semantic Web and Linked Data

## Overview
The **Semantic Web** represents the evolution from a "Web of Documents" (designed for humans) to a "Web of Data" (designed for both humans and machines). The goal is to make information explicit and interoperable across different databases.

## Core Framework
The architecture is based on several interconnected layers:
- **[[Ontology]]**: Defines the conceptual framework using **OWL**.
- **[[Linked Data]]**: Populates the framework with specific instances using **[[Resource Description Framework (RDF)]]**.
- **Knowledge Graphs**: The resulting integrated data resource.

## Technical Foundations
- **[[RDF Triple]]**: The basic unit of information (Subject $\rightarrow$ Predicate $\rightarrow$ Object).
- **[[RDF Graph]]**: A collection of triples that can be merged globally using URIs.
- **[[SPARQL]]**: The standard query language for RDF data.
- **[[Entailment Regime]]**: Rules for logical inference over RDF data.

## Linked Open Data (LOD)
Following the principles defined by **[[Tim Berners-Lee]]**, **[[Linked Open Data (LOD)]]** uses HTTP URIs and open licenses to create a global, interlinked cloud of data.

## Conclusion
By moving towards a structured, semantic representation of knowledge, the web transforms from a collection of isolated silos into a globally accessible and machine-understandable database.
