# JSP Standard Tag Library (JSTL)
A collection of useful JSP tags that encapsulate core functionality common to many JSP applications, such as iteration, conditionals, internationalization, and XML manipulation. It is used to reduce the amount of Java code (scriptlets) in JSP pages.
