# Elasticsearch

A distributed, RESTful search and analytics engine based on Apache Lucene.

## Characteristics
- **Distributed**: Scales horizontally across multiple nodes.
- **Schema-less**: Uses JSON for document representation.
- **Real-time**: Provides near real-time search capabilities.
- **Ecosystem**: Part of the ELK stack (Elasticsearch, Logstash, Kibana).
